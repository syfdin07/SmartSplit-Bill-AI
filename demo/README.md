# Demo Folder

Folder ini berisi video demo aplikasi SmartSplit Bill AI.

## 📹 Video Demo

Letakkan video demo Anda di sini dengan nama:
- `demo_video.mp4` (Recommended)
- atau `demo_video.mov`

## 📝 Cara Menambahkan Video:

### Opsi A: Copy Video ke Folder Ini

```bash
# Copy video ke folder demo/
copy "path\to\your\video.mp4" "demo\demo_video.mp4"

# Commit dan push
git add demo/demo_video.mp4
git commit -m "Add demo video"
git push
```

### Opsi B: Upload ke YouTube/Drive (Recommended)

Lebih baik upload ke:
- YouTube (Unlisted)
- Google Drive (Anyone with link)

Lalu tambahkan link di README.md

## ⚠️ Catatan:

- Video akan di-track dengan Git LFS
- Ukuran maksimal: ~100 MB (GitHub limit)
- Durasi recommended: 2-3 menit
- Format: MP4 (H.264)

## 🎬 Isi Video Demo:

1. Intro aplikasi (10 detik)
2. Upload struk (30 detik)
3. Verifikasi data (30 detik)
4. Input peserta (20 detik)
5. Assign items (40 detik)
6. Hasil split (30 detik)
7. Outro (10 detik)

**Total: ~2-3 menit**
